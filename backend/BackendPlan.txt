# New2Fit Backend Migration Plan

## Tech Stack

1.  **Framework:** FastAPI

2.  **Database:** PostgreSQL (Raw)
    *   Replacing Supabase's managed Postgres/RPCs.

3.  **ORM (Object-Relational Mapper):** SQLAlchemy
    *   Python's equivalent to Hibernate/JPA.
    *   Used to define "Entities" (Python classes mapped to SQL tables).

4.  **Database Migrations:** Alembic
    *   Works with SQLAlchemy to track changes to Entities and automatically generate SQL migration scripts to update the database schema.
    *   Equivalent to Flyway/Liquibase.

5.  **Data Validation/DTOs:** Pydantic
    *   Built into FastAPI.
    *   Used to define the shape of incoming JSON requests and outgoing responses (DTOs).

6.  **Authentication:** Auth0
    *   Replacing Supabase Auth.
